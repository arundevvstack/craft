# **App Name**: Craftsmac Labs

## Core Features:

- Dynamic Content Rendering: Render all website pages, sections, texts, images, and navigation menus dynamically from Firestore, ensuring all client-facing content is updated from the CMS.
- Admin Authentication: Secure administrative login and session management using Firebase Authentication for content editors.
- Comprehensive CMS Interface: Provide an intuitive admin dashboard for managing all website content, including pages, section titles, texts, feature lists, technology descriptions, navigation, contact information, social media links, and technology showcase items, with CRUD operations facilitated by Firestore.
- Image & Asset Management: Allow administrators to upload, manage, and associate images for all website sections and technology showcase items using Firebase Storage.
- Contact Form Management: Implement a user-facing contact form that captures submissions and stores them securely in a Firestore collection, accessible and manageable via the Admin Dashboard.
- AI Content Tool: An AI-powered tool within the CMS to assist administrators in generating concise meta descriptions or alternative headline suggestions for new technology showcase items and content sections, improving SEO and content variety.

## Style Guidelines:

- Primary interactive color (Steel Blue): #2083E0 (A strong, vibrant blue for CTAs and branding highlights, evoking professionalism and technology).
- Background color (Dark Grey): #1A1F23 (A very dark, subtly cool grey serving as the main background, providing a deep tech aesthetic and excellent contrast).
- Accent color (Cyan): #69CCD0 (A lighter, analogous cyan for subtle highlights, visual cues, and secondary interactive elements, complementing the primary blue).
- Headline font: 'Space Grotesk' (a sans-serif font with a techy, computerized feel, suitable for large typography and impactful statements).
- Body text font: 'Inter' (a modern sans-serif for clean, legible body content across all pages, complementing the headline font for an objective, engineered look).
- Use minimalist, crisp SVG icons and Lottie animations that align with robotics and industrial engineering themes. Ensure diagrams like robotic arms, actuators, and factory layouts are animated and clear.
- Achieve a clean and expansive layout with large typography, generous white/dark space, smooth scrolling, and parallax effects, emphasizing a high-end, modern engineering aesthetic. Fully responsive for all device sizes.
- Subtle Framer Motion animations for hover states, card animations on scroll, hero section elements, and animated workflow diagrams. Animations should be fluid, purposeful, and contribute to a premium user experience.
